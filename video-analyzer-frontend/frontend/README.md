# FrameSeek 前端 MVP

QD-DETR 视频片段检索与高光检测的 Vue 3 前端原型。

与服务器模型服务的字段和接口约定见 [前端接口说明.md](./前端接口说明.md)。

## 本地运行

```powershell
cd frontend
npm install
npm run dev
```

打开终端显示的本地地址，选择一个视频并执行查询。默认是 **Mock 演示**，结果由浏览器生成，仅用于检查界面和交互，不代表模型推理结果。

## 接入后端

在页面的“运行模式”切换至 **HTTP 后端**，启动符合 [前端接口说明.md](./前端接口说明.md) 的服务。前端依次调用 `POST /api/videos`、`GET /api/videos/{video_id}`（处理时轮询）和 `POST /api/search`。Vite 将 `/api` 代理到 `http://localhost:8000`；端口不同可在 `vite.config.ts` 修改。

页面显示上传、特征提取、检索状态，以及本次查询的浏览器端耗时和缓存命中。缓存只在当前页面内有效，按运行模式、视频、查询和 Top-K 区分；刷新页面会清空。HTTP 模式下后端返回的 `inference_mode` 会显示在顶栏，缺失时显示“模型待确认”，不据此推断真实模型。接口响应会检查片段时间、得分和高光数组。

选取 MP4、WebM、MOV 文件后须等浏览器读取时长；部分 MOV 编码可能无法在浏览器播放。HTTP 模式确实会向后端上传文件，Mock 模式不会上传。真实联调、跨浏览器/分辨率验证、最终系统截图和演示视频需要在提供后端及测试素材的环境中完成。
